# Хроники Антарии

Браузерная RPG о деревне, которая должна стать городом. Медленный рост, ремесло,
торговля, оборона. Читается как книга, а не проходится как список квестов.

## Запуск

```bash
npm install
npm run dev
```

Открыть адрес, который покажет Vite (по умолчанию http://localhost:5173).

## Сборка

```bash
npm run build      # проверка типов + сборка в dist/
npm run preview    # посмотреть собранное локально
npm run typecheck  # только проверка типов
```

## Структура

```
src/
  core/      чистая логика: состояние, время, события. Не знает про DOM и Canvas
  data/      типы и схемы данных
  content/   сам контент: ресурсы, рецепты, постройки, сцены (только читается)
  render/    отрисовка сцены на Canvas
  ui/        экранные формы и HUD
public/      статические файлы
```

## Сохранение в git

Всё, что нужно в обычной работе, — одна команда:

```bash
npm run push                    # сохранить всё и отправить на GitHub
npm run push "M1: первая глава" # то же, но со своим описанием
```

Git — это история версий в папке `.git`: каждый снимок можно вернуть.
GitHub — копия этой истории в интернете. `npm run push` делает снимок и отправляет его туда.

Первый раз репозиторий нужно связать с GitHub (одна команда в папке проекта):

```bash
git remote add origin https://github.com/ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
npm run push
```

При первом push откроется браузер для входа в GitHub — дальше вход запоминается
через Git Credential Manager, и больше спрашивать не будет.


## Публикация на GitHub Pages

Сборка выкладывается автоматически при пуше в `main` (`.github/workflows/deploy.yml`).
`base: './'` уже настроен, поэтому игра работает и из подпапки репозитория.

Что нужно сделать один раз, вручную:

1. Создать репозиторий на GitHub и запушить туда `main`.
2. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
3. Дождаться прогона workflow во вкладке **Actions**. Адрес будет вида
   `https://<логин>.github.io/<репозиторий>/`.

Дальше каждый пуш в `main` обновляет игру сам. Локальная сборка при этом не меняется:
`npm run build` по-прежнему собирает `dist/` в любую папку.
